# Python Web Scraping & Data Engineering Portfolio

This repository contains projects demonstrating my skills in web scraping, dynamic content handling, LLM integration, and data validation.

## Projects

### 1. Dynamic Content Scraper
- **Tech:** Python, Selenium, Pandas
- **Description:** Handles JavaScript-rendered pages and infinite scrolling. Extracts structured data into CSV.
- **Key Feature:** Implements headless browser automation for efficiency.

### 2. LLM-Enhanced Data Parser
- **Tech:** Python, OpenRouter API, Requests
- **Description:** Uses Large Language Models to parse unstructured text into structured JSON.
- **Key Feature:** Demonstrates integration of AI frameworks for data cleaning.

### 3. Data Validation & Dockerization
- **Tech:** Python, Pandas, Docker
- **Description:** Ensures data quality by checking for missing values and duplicates. Containerized using Docker for reproducibility.

## How to Run
1. Clone the repo: `git clone https://github.com/yourusername/python-web-scraping-portfolio.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the scraper: `python dynamic_scraper.py`
